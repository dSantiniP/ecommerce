# Sistema de Gerenciamento de Produtos

Projeto desenvolvido em **Java** durante meus estudos de Programação Orientada a Objetos e desenvolvimento Back-end.

A aplicação funciona pelo terminal e permite realizar operações básicas de gerenciamento de produtos.

## Funcionalidades

* Cadastrar produtos
* Listar produtos
* Atualizar produtos
* Excluir produtos
* Validar algumas entradas do usuário
* Gerar ID automaticamente para os produtos

## Tecnologias

* Java
* Programação Orientada a Objetos (POO)
* ArrayList
* Scanner
* Tratamento de exceções
* Git e GitHub

## Estrutura do projeto

O projeto foi separado em algumas classes para organizar melhor as responsabilidades:

```text
src/
├── controllers/
│   └── StoreController.java
├── mains/
│   └── App.java
├── models/
│   └── Store.java
├── repositories/
│   └── StoreRepository.java
└── services/
    └── StoreService.java
```

### Principais classes

**Store**
Representa o produto e seus atributos.

**StoreController**
Responsável pela interação com o usuário e entrada dos dados.

**StoreService**
Responsável por algumas regras e validações da aplicação.

**StoreRepository**
Responsável por armazenar e manipular os produtos em memória.

**App**
Classe principal responsável por iniciar o sistema e apresentar o menu.
